STEP 1: FEATURE EXTRACTION
─────────────────────────────────────────────

For each equation `E: L = R`, list every variable letter that appears on each side,
counting multiplicity. Then derive:

  size(E)  — count every variable occurrence on L plus every occurrence on R
             e.g. `x*(y*x) = y` → L has x,y,x (3) + R has y (1) → size=4

  vars(E)  — count distinct letters appearing anywhere in E (ignore multiplicity)
             e.g. `x*(y*x) = y` → {x,y} → vars=2

  imb(E)   — for each distinct variable v, take |count(v,L) − count(v,R)|, then sum
             e.g. `x*(y*x) = y` → x: |2−0|=2, y: |1−1|=0 → imb=2

  bare(E)  — TRUE when exactly one side is a single lone variable (no `*`)
             e.g. `x = y*x` → bare=TRUE;  `x*y = y*x` → bare=FALSE

  LP(E)    — TRUE when the leftmost variable token on L equals the leftmost on R
             e.g. `x*(y*z) = x*w` → both start with x → LP=TRUE

  RP(E)    — TRUE when the rightmost variable token on L equals the rightmost on R
             e.g. `x*y = z*y` → both end with y → RP=TRUE

  SET(E)   — TRUE when the set of distinct variable letters on L equals that on R
             e.g. `x*(y*x) = y*x` → L:{x,y} = R:{x,y} → SET=TRUE

  XOR(E)   — TRUE when every variable appears an even number of times on EACH side,
             OR an odd number on each side (parity matches per variable per side)
             e.g. `x*y = y*x` → x:odd/odd, y:odd/odd → XOR=TRUE

  AB(E)    — TRUE when every variable has the same total count on L as on R
             e.g. `x*y = y*x` → x:1=1, y:1=1 → AB=TRUE
