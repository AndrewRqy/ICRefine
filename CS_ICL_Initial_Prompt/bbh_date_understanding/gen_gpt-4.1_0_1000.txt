# DATE CALCULATION CHEAT SHEET

## 1. **Interpreting "Today" from Context**
- If told "Tomorrow is X", then **Today = X - 1 day**.
- If told "Yesterday was X", then **Today = X + 1 day**.
- If told "The day before yesterday was X", then **Today = X + 2 days**.
- If told "It was X a week ago", then **Today = X + 7 days**.
- If told "Today is the nth anniversary of event on X", then **Today = X + n years**.
- If told "Today is the last day of [month/year]", use the actual last day (e.g., Jan 31, Feb 28/29, Dec 31, etc.).
- If told "Today is the palindrome day of 2020", **Today = 02/02/2020**.

---

## 2. **Date Arithmetic**
### a. **Adding/Subtracting Days**
- **Tomorrow**: Add 1 day.
- **Yesterday**: Subtract 1 day.
- **24 hours later**: Add 1 day.
- **10 days ago**: Subtract 10 days.
- **One week ago**: Subtract 7 days.
- **One week from today**: Add 7 days.

### b. **Adding/Subtracting Months**
- **A month ago**: Subtract 1 month, keep the day if possible.
    - If the previous month has fewer days, use the last day of that month (e.g., March 31 → Feb 28/29).
- **A month from today**: Add 1 month, same rule as above.

### c. **Adding/Subtracting Years**
- **A year ago**: Subtract 1 year, keep the same month and day if possible.
    - If the previous year doesn't have that date (e.g., Feb 29), use Feb 28.

---

## 3. **Special Cases**
### a. **Leap Years**
- Leap years: Years divisible by 4, except years divisible by 100 unless also by 400.
- Feb 29 exists only in leap years (e.g., 2000, 2004, 2016, 2020).
- If subtracting a year from Feb 29 (leap year), result is Feb 28 (non-leap year).

### b. **Month Lengths**
- Jan: 31, Feb: 28/29, Mar: 31, Apr: 30, May: 31, Jun: 30, Jul: 31, Aug: 31, Sep: 30, Oct: 31, Nov: 30, Dec: 31.

### c. **UK Date Format**
- If told "Today is 02/01/1987 in UK format", interpret as **2nd Jan 1987** (MM/DD/YYYY: 01/02/1987).

### d. **US Thanksgiving**
- Fourth Thursday in November.
    - Find the first Thursday, then add 21 days.

### e. **Counting Days Across Months**
- When adding/subtracting days that cross months, count the days in each month carefully.
    - Example: From Mar 20, add 176 days:
        - Days left in March: 31 - 20 = 11
        - Subtract from total, then move through each month in order.

---

## 4. **Anniversaries and Recurring Events**
- **nth anniversary**: Add n years to the original date.
- **nth visit on the same day each month**: Start from the first event, add (n-1) months.

---

## 5. **Common Pitfalls**
- **Year/Month/Day Mismatches**: Always check if the answer options have the correct year.
- **Off-by-One Errors**: Double-check if "today" is the day before or after the reference date.
- **Nonexistent Dates**: E.g., Dec 32, Feb 29 in non-leap years—adjust accordingly.

---

## 6. **Step-by-Step Approach**
1. **Identify "today"** based on the context.
2. **Determine the operation** (add/subtract days, weeks, months, years).
3. **Account for month/year boundaries** (e.g., Dec 31 + 1 day = Jan 1 next year).
4. **Check for leap years** if dealing with February.
5. **Format the answer** as MM/DD/YYYY.
6. **Match your result to the closest option** if there are typos or mismatches in the options.
