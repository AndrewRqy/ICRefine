## Cheat Sheet: Truth-Teller/Liar Chain Reasoning

### 1. **General Approach**
- **Always start with the person whose truthfulness is given.**
- **Work step by step, one statement at a time, in the order given.**
- **At each step, determine if the current person's statement is correct (truth-teller) or incorrect (liar) based on the previous person's status.**
- **Continue until you reach the person in question.**

---

### 2. **Key Rules**

#### A. **If a person says "X tells the truth":**
- If X is a truth-teller, the statement is true → the speaker is a truth-teller.
- If X is a liar, the statement is false → the speaker is a liar.

#### B. **If a person says "X lies":**
- If X is a liar, the statement is true → the speaker is a truth-teller.
- If X is a truth-teller, the statement is false → the speaker is a liar.

---

### 3. **Chain Reasoning Patterns**

#### **Pattern 1: All "tells the truth" statements**
- If the chain is all "A says B tells the truth", and the first person is a truth-teller, **everyone in the chain is a truth-teller**.
- If the first person is a liar, **everyone in the chain is a liar**.

#### **Pattern 2: All "lies" statements**
- If the chain is all "A says B lies", and the first person is a truth-teller, **the truth/lie status alternates at each step**.
- If the first person is a liar, **the truth/lie status also alternates at each step**.

#### **Pattern 3: Mixed statements**
- **Apply the rules above at each step.**
- **Keep a running list of each person's status as you go.**

---

### 4. **Step-by-Step Example Template**

Suppose you have:
- "A tells the truth."
- "B says A lies."
- "C says B tells the truth."
- "D says C lies."
- "E says D tells the truth."
- Does E tell the truth?

**Step-by-step:**
1. A is a truth-teller.
2. B says "A lies" → A is a truth-teller, so B is lying → B is a liar.
3. C says "B tells the truth" → B is a liar, so C is lying → C is a liar.
4. D says "C lies" → C is a liar, so D is telling the truth → D is a truth-teller.
5. E says "D tells the truth" → D is a truth-teller, so E is telling the truth → **E is a truth-teller**.

---

### 5. **Tips for Difficult Chains**

- **Write down each person’s status as you go.**
- **If you get stuck, try working backward from the person in question.**
- **If the chain loops or is long, keep a list:**
  - A: Truth
  - B: Lie
  - C: Lie
  - D: Truth
  - E: Truth

---

### 6. **Common Pitfalls**

- **Don’t assume alternation unless all statements are "lies".**
- **Don’t skip steps; each depends on the previous.**
- **Be careful with double negatives: "X says Y lies" when Y says "Z lies".**

---

### 7. **Quick Reference Table**

| Statement Type         | Previous Person | Current Person |
|-----------------------|-----------------|---------------|
| "X tells the truth"   | Truth-teller    | Truth-teller  |
| "X tells the truth"   | Liar            | Liar          |
| "X lies"              | Truth-teller    | Liar          |
| "X lies"              | Liar            | Truth-teller  |

---

### 8. **Practice: Try to Paraphrase Each Step**

- After each step, say: "Since [previous person] is a [truth-teller/liar], [current person's] statement is [true/false], so [current person] is a [truth-teller/liar]."
