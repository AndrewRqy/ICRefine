# Truth-Teller/Liar Chain Cheat Sheet

## 1. **General Approach**

- **Start with the given fact** (e.g., "Amberly lies" or "Jim tells the truth").
- **Work through each statement in order**, determining the truth/lie status of each person based on the previous person's status.
- **Each statement is about the previous person's truthfulness or lying.**
- **If someone says "X tells the truth"**:
  - If X tells the truth, the statement is true → the speaker tells the truth.
  - If X lies, the statement is false → the speaker lies.
- **If someone says "X lies"**:
  - If X lies, the statement is true → the speaker tells the truth.
  - If X tells the truth, the statement is false → the speaker lies.

---

## 2. **Step-by-Step Reasoning Template**

For each person in the chain:
- **Identify the subject** of their statement (who are they talking about?).
- **Determine the truth/lie status** of the subject (from previous steps).
- **Apply the rule**:
  - If the statement matches the subject's status, the speaker tells the truth.
  - If the statement does not match the subject's status, the speaker lies.

## 3. **Key Patterns**

### A. **Alternating Chains**
- If the chain is all "tells the truth" statements, and the first person is a liar, **everyone in the chain is a liar**.
- If the chain is all "tells the truth" statements, and the first person is a truth-teller, **everyone in the chain is a truth-teller**.

### B. **"Lies" Statements**
- If the statement is "X lies":
  - If X is a liar, the speaker tells the truth.
  - If X is a truth-teller, the speaker lies.

### C. **Switching Statement Types**
- When the statement type switches between "tells the truth" and "lies", **carefully apply the rule for each**.
- **Keep a running list** of each person's status as you go.

---

## 4. **Common Pitfalls**

- **Don’t assume alternation**: The truth/lie status does NOT always alternate down the chain. It depends on the statement type and the subject's status.
- **Always check the subject's status** before deciding the speaker's status.
- **If you get stuck, write out each step** in a table or list.
