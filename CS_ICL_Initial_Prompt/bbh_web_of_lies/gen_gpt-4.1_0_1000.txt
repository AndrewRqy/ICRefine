## Truth-Teller/Liar Chain Cheat Sheet

### 1. **Core Principle**
- **Truth-tellers**: All their statements are true.
- **Liars**: All their statements are false.

### 2. **Statement Types**
- **"X says Y tells the truth"**: X claims Y is a truth-teller.
- **"X says Y lies"**: X claims Y is a liar.

### 3. **Step-by-Step Reasoning Process**

#### a. **Start with the Given**
- The first statement always tells you the truth/lie status of one person. **Write this down.**

#### b. **Work Forward, One Statement at a Time**
- For each subsequent statement:
    - **If the speaker is a truth-teller:** Their statement is true.
    - **If the speaker is a liar:** Their statement is false.

#### c. **How to Interpret Each Statement**
- **If X says "Y tells the truth":**
    - If X is a truth-teller: Y is a truth-teller.
    - If X is a liar: Y is a liar.
- **If X says "Y lies":**
    - If X is a truth-teller: Y is a liar.
    - If X is a liar: Y is a truth-teller.

#### d. **Chain the Reasoning**
- **Update the status** (truth-teller/liar) for each person as you go.
- **Always use the most recent, confirmed status** for each person.

#### e. **Final Step**
- When you reach the last person, **check if their statement matches the actual status** of the person they refer to.
    - If their statement matches reality, they are a truth-teller.
    - If their statement does not match reality, they are a liar.

---

### 4. **Quick Reference Table**

| Speaker's Status | Statement Type         | Target's Status |
|------------------|-----------------------|-----------------|
| Truth-teller     | "Y tells the truth"   | Truth-teller    |
| Truth-teller     | "Y lies"              | Liar            |
| Liar             | "Y tells the truth"   | Liar            |
| Liar             | "Y lies"              | Truth-teller    |

---

### 5. **Common Pitfalls & Tips**
- **Don’t skip steps**: Always write down each person’s status as you go.
- **If you get stuck, work backwards**: Sometimes, if the chain is confusing, try deducing from the end.
- **If a statement refers to someone whose status you haven’t determined yet, pause and fill in the chain up to that point.**
- **If you make a mistake, retrace your steps from the last known correct status.**

---

### 6. **Example Walkthrough (Template)**

Suppose:  
A tells the truth.  
B says A lies.  
C says B tells the truth.  
D says C lies.  
E says D tells the truth.  
Does E tell the truth?

**Step-by-step:**
1. A: truth-teller (given)
2. B says "A lies"  
   - B's claim is false (since A tells the truth), so B is a liar.
3. C says "B tells the truth"  
   - B is a liar, so C's claim is false, so C is a liar.
4. D says "C lies"  
   - C is a liar, so D's claim is true, so D is a truth-teller.
5. E says "D tells the truth"  
   - D is a truth-teller, so E's claim is true, so E is a truth-teller.  
**Answer: Yes**

---

### 7. **If You Lose Track**
- **Write a list**:  
  - Person: Status (T/L)
- **Update as you go**.
- **Double-check**: For each statement, does the speaker’s status match the truth/lie of their claim?

---

### 8. **Special Cases**
- **Odd number of "lies" statements in a row**: Flips the status.
- **Even number of "lies" statements in a row**: Returns to original status.

---

**Summary:**  
- Always start from the given.
- For each statement, use the table above to determine the next person’s status.
- At the end, check if the last person’s statement matches the actual status of the person they refer to.
