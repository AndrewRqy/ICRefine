**SVG Path Shapes Cheat Sheet for Difficult Examples**

---

### 1. **Basic Commands**

- **M x,y**: Move to coordinate (x,y) without drawing.
- **L x,y**: Draw a straight line from current point to (x,y).
- **A rx,ry x-axis-rotation large-arc-flag,sweep-flag x,y**: Draw an elliptical arc from current point to (x,y) with radii rx, ry.

---

### 2. **Identifying Polygons (Closed Shapes with L commands)**

- Count **unique points** connected by lines.
- If the path returns to the starting point, it forms a **closed polygon**.
- Number of unique points = number of polygon sides.

| Number of Sides | Polygon Name  |
|-----------------|---------------|
| 3               | Triangle (J)  |
| 4               | Rectangle (H), Kite (D), Trapezoid (K) |
| 5               | Pentagon (G)  |
| 6               | Hexagon (C)   |
| 7               | Heptagon (B)  |
| 8               | Octagon (F)   |

---

### 3. **Distinguishing Between Quadrilaterals**

When the polygon has 4 sides, distinguish between:

- **Rectangle (H)**:
  - Opposite sides equal and parallel.
  - All angles ~90°.
  - Coordinates show horizontal and vertical lines (same x or y for opposite points).
  
- **Kite (D)**:
  - Two pairs of **adjacent** sides equal in length.
  - Check side lengths using distance formula:
    \[
    d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
    \]
  - Adjacent sides equal, not opposite.
  
- **Trapezoid (K)**:
  - At least one pair of parallel sides.
  - Sides may not be equal.
  - Usually no right angles.
  - Check if only one pair of sides have equal y or x coordinates (indicating parallelism).

**Tip:** If rectangle and trapezoid both fit, prefer rectangle if all angles are right angles and opposite sides equal.

---

### 4. **Recognizing Lines**

- Only two points connected by a single **L** command after an **M**.
- No return to start point.
- Answer: **Line (E)**.

---

### 5. **Identifying Ellipses and Circles (Using A commands)**

- Two **A** commands with same radii (rx = ry) and connecting start and end points.
- The path forms a closed curve with arcs.
- If rx = ry and rotation = 0°, it's a **circle (A)** or **ellipse (K)**.
- If rotation ≠ 0°, it's an **ellipse (K)**.
- If the path uses two arcs to complete the shape, it's an ellipse or circle.

**Note:**  
- Circle is a special case of ellipse.  
- If both circle and ellipse options exist, and rotation ≠ 0°, choose ellipse.

---

### 6. **Identifying Sector (Pie Slice)**

- Path contains **M**, **L**, and **A** commands.
- Starts at center point (M), draws a line (L) to arc start, then arc (A), then line (L) back to center.
- Shape looks like a "wedge" or "pie slice".
- Answer: **Sector (I)**.

---

### 7. **Step-by-Step Approach to Difficult Examples**

1. **Break down the path commands** into sequences of points.
2. **Count unique points** connected by lines.
3. **Check if path closes** (last point connects to first).
4. **For polygons:**
   - Count sides.
   - For quadrilaterals, calculate side lengths to distinguish kite, rectangle, trapezoid.
5. **For arcs:**
   - Identify if two arcs form a closed ellipse or circle.
   - Check radii and rotation.
6. **For sectors:**
   - Look for combination of lines and arcs forming a wedge.
7. **For lines:**
   - Only two points, no closure.

---

### 8. **Distance Formula for Side Lengths**

Given two points \( (x_1, y_1) \) and \( (x_2, y_2) \):

\[
d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\]

Use this to:

- Compare adjacent sides for kite.
- Compare opposite sides for rectangle.
- Check parallelism by comparing y or x coordinates.

---

### 9. **Parallelism Check**

- Two points have same y-coordinate → horizontal line.
- Two points have same x-coordinate → vertical line.
- If only one pair of sides is parallel → trapezoid.
- If two pairs of sides parallel and all angles ~90° → rectangle.

---

### 10. **Summary Table for Quick Reference**

| Shape     | Key Features in SVG Path                                  | Answer Option |
|-----------|-----------------------------------------------------------|---------------|
| Line      | 2 points, 1 line, no closure                               | (E)           |
| Triangle  | 3 points, closed loop                                      | (J)           |
| Kite      | 4 points, closed, 2 pairs adjacent equal sides            | (D)           |
| Rectangle | 4 points, closed, opposite sides equal & parallel, right angles | (H) or (K)*   |
| Trapezoid | 4 points, closed, at least one pair parallel sides        | (K)           |
| Pentagon  | 5 points, closed loop                                      | (G)           |
| Hexagon   | 6 points, closed loop                                      | (C)           |
| Heptagon  | 7 points, closed loop                                      | (B)           |
| Octagon   | 8 points, closed loop                                      | (F)           |
| Ellipse   | 2 arcs forming closed curve, rx ≠ ry or rotation ≠ 0      | (K)           |
| Circle    | 2 arcs forming closed curve, rx = ry and rotation = 0     | (A) or (K)*   |
| Sector    | Combination of lines and arc forming wedge shape           | (I)           |

*If both circle and ellipse options exist, and rotation ≠ 0°, choose ellipse.

---

### 11. **Tips for Exam**

- **Always count unique points connected by lines** to determine polygon sides.
- **Check if path closes** by returning to start point.
- **For quadrilaterals, calculate side lengths** to distinguish kite, rectangle, trapezoid.
- **For arcs, check radii and rotation** to decide ellipse vs circle.
- **Look for arcs combined with lines forming wedges** → sector.
- **If only two points and one line → line.**
